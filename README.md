# GPT-3 Modern UI Website

A modern and responsive GPT-3 landing page built using React.js and Vite.

## 📌 Features

- Modern UI/UX Design
- Fully Responsive Layout
- Reusable React Components
- Clean Folder Structure
- Fast Development with Vite

## 🛠️ Built With

- React.js
- Vite
- CSS3
- JavaScript (ES6)

## 📂 Folder Structure

src/
│
├── assets/
├── components/
├── container/
├── App.jsx
├── main.jsx


## ⚙️ Installation & Setup

Clone the repository:

git clone https://github.com/nehanegi13/GPT-3-Website.git


Go into the project directory:

cd GPT-3-Website


Install dependencies:

npm install


Run development server:

npm run dev
